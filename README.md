# HackerRank EST1 Practice — Python 3 & C++17

This repository was empty when preparation began. These files provide reusable core implementations for the EST1 topics in the supplied four-page practice list.

## Files
- `Python/solutions.py` — Python 3 implementations.
- `Cpp/solutions.cpp` — C++17 implementations.

## Included challenge logic
Simple Array Sum, Plus Minus, Diagonal Difference, CamelCase, Super Reduced String, Pangrams, Recursive Digit Sum, The Power Sum, Between Two Sets, Restaurant (GCD/LCM), Two Strings, Hash Tables: Ransom Note, Balanced Brackets, Equal Stacks, Ice Cream Parlor, Closest Numbers, Pairs, Triple Sum, Maximum Subarray Sum modulo m, Lonely Integer, Flipping Bits, Maximizing XOR, and primality testing.

## Important submission note
These are **core function implementations**, not complete HackerRank submission wrappers for every challenge. HackerRank challenges use different input formats and required function names. Copy the relevant function into the matching challenge editor and add its required input/output wrapper. The repository does not submit solutions to HackerRank automatically.
